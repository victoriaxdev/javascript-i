# Exercício 12

## O que é programação?
A programação cria meios de se comunicar com o computador por meio de comandos (programas).

## O que é JavaScript?
JavaScript é uma linguagem de programação conhecida por sua versatilidade.

## Qual a função do JavaScript em um navegador Web?
Em um navegador, o JavaScript permite criar interatividade entre usuário e sistema.

Ele possibilita:
- Atualização de conteúdo
- Animações
- Menus dinâmicos
- Jogos e aplicações interativas
